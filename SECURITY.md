# Security

Live Link 0.1.0 is intended for trusted private local networks. Pairing limits
access but does not encrypt control messages or PCM audio. Do not expose the
service to the public internet. Persistent device trust is not implemented.

For vulnerabilities, use the repository's private GitHub vulnerability reporting
feature once enabled by its maintainer. Do not post active credentials or
sensitive exploit details in public issues. No response-time guarantee is made.
