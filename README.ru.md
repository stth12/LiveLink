## Ещё одна точка прослушивания вашей сессии

Live Link передаёт стереокопию звука из DAW в нативное приложение на iPhone.
Обычный аудиовыход продолжает работать, а каждым приёмником можно управлять
отдельно из панели Windows.

| Windows | Соединение | iPhone |
| :--- | :---: | :--- |
| VST3-плагин · панель управления · фоновый процесс | Передача PCM по локальной сети | Интерфейс SwiftUI · воспроизведение RemoteIO |

> **Ранняя версия · 0.1.0**<br>
> Сборки Windows и автоматические тесты проходят. Пользователь подтвердил
> подключение по локальной сети и воспроизведение на реальном iPhone. Передача по USB пока не реализована.

## Возможности

| Возможность | Подробности |
| :--- | :--- |
| Сохранение обычного аудиовыхода | VST3 пропускает стереосигнал без изменения битов и создаёт отдельную сетевую копию |
| Несколько приёмников | До 16 сессий с отдельными настройками громкости, отключения звука и моно |
| Подключение | Обнаружение Bonjour, ручной ввод IPv4 и восьмизначный PIN |
| Настройка буфера | Восстановление порядка пакетов, адаптивная буферизация и ограниченная коррекция дрейфа |
| Нативное приложение | Интерфейс SwiftUI, звук RemoteIO и поддержка фонового аудио |
| Запуск вместе с Windows | Установщик, необязательный автозапуск и настройка брандмауэра для частной сети |

## Быстрый старт

1. **Windows:** соберите и установите панель управления, фоновый процесс и
   VST3-плагин по [инструкции для Windows](docs/BUILD_WINDOWS.md).
2. **iPhone:** соберите, подпишите и установите приложение через
   [xtool](docs/BUILD_IOS_XTOOL.md) или [Xcode](docs/BUILD_IOS.md).
3. **Подключение:** подключите устройства к одной доверенной локальной сети.
   Откройте Live Link, разрешите доступ к локальной сети на iPhone,
   выберите компьютер и введите его PIN.
4. **Воспроизведение:** добавьте Live Link на стереомастер DAW и запустите
   музыку. Оставьте обычный аудиовыход DAW включённым.

Если компьютер не обнаруживается автоматически, введите его IPv4-адрес.
Подробности — в [инструкции по установке и использованию](docs/INSTALLATION.md).

## Сборка из исходников

### Windows

Нужны компоненты Visual Studio для разработки настольных приложений на C++,
Windows SDK, CMake и Git. CMake загружает JUCE 8.0.6 из официального репозитория.

```powershell
./scripts/build_windows.ps1
./scripts/run_tests.ps1 -Integration
./scripts/package_windows.ps1 -ISCC 'C:/Program Files (x86)/Inno Setup 6/ISCC.exe'
```

### iOS

После настройки xtool и Darwin Swift SDK:

```sh
bash scripts/build_ios_xtool.sh
```

По умолчанию IPA создаётся без подписи. Для установки на обычный iPhone
нужны подпись и профиль подготовки. Результаты сборки исключены из Git;
готовые сборки распространяются отдельно по мере доступности.

## Текущие ограничения

- **Доверенная сеть:** управляющие сообщения и аудио не шифруются.
- **Передача:** только IPv4; USB пока недоступен.
- **Источник:** один плагин захватывает звук на учётную запись Windows.
- **Аудио:** преобразование частоты использует линейную интерполяцию.
  Сквозная задержка и синхронное звучание нескольких устройств не измерены.
- **Проверки:** совместимость с разными DAW, несколько физических приёмников
  и длительная работа на устройствах ещё требуют тестирования.
